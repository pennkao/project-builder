| 层级           | 建议类名            | 语义     | 说明                            |
| ------------ | --------------- | ------ | ----------------------------- |
| **Layer 1**  | `.bg-page`      | 页面主背景  | 页面最底层背景，整体基调                  |
| **Layer 2**  | `.bg-block`     | 区块背景   | 页面分区/模块背景，如 Header、Footer、内容区 |
| **Layer 3**  | `.bg-container` | 内容承载层  | 卡片、面板、文章容器等                   |
| **Layer 3a** | `.bg-card`      | 卡片专用   | 继承 container，针对独立信息块          |
| **Layer 3b** | `.bg-content`   | 文本/文章区 | 继承 container，用于文字或列表          |
| **Layer 4**  | `.bg-focus`     | 视觉强调层  | CTA、品牌色、重要模块                  |
| **Layer 5a** | `.bg-overlay`   | 遮罩层    | 弹窗、浮层遮罩                       |
| **Layer 5b** | `.bg-state`     | 临时状态层  | hover、选中、提示等状态                |
| **Layer 6**  | `.bg-reverse`   | 反转/深色层 | 深色背景或暗黑模式区块                   |
